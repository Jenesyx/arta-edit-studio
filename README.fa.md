## این چیه؟

Arta Edit Studio مجموعه‌ای از **اسکیل‌ها (دستورهای اسلشی) برای [Claude Code](https://claude.com/claude-code)** به‌همراه ابزارهای پایتون و Node است که این اسکیل‌ها اجراشون می‌کنن. ویدیوت رو توی یک پوشه می‌ذاری و چیزی شبیه این می‌نویسی:

<div dir="ltr">

```
/reel-story my-video  I explain how my startup started. Already cut and coloured. Comment keyword: JOIN.
```

</div>

…و Claude می‌شه تدوینگر تو. حرف‌هات رو با زمان دقیق هر کلمه پیاده می‌کنه، برای هر چند ثانیه یک «بیت» تصویری برنامه‌ریزی می‌کنه، از ویدیوهای B-roll خودت بهترین لحظه‌ها رو انتخاب می‌کنه، انیمیشن‌ها رو می‌نویسه، ویدیوی نهایی ۱۰۸۰×۱۹۲۰ رو رندر می‌کنه و قبل از تحویل، فریم به فریم چکش می‌کنه.

این پروژه **اول برای تولیدکننده‌های محتوای فارسی** ساخته شده — متن راست‌به‌چپ، اعداد فارسی، فونت فارسی و تنظیمات Whisper برای فارسی همه از قبل حل شدن — ولی برای هر زبانی که Whisper بفهمه (انگلیسی، عربی، آلمانی، ترکی و…) هم کار می‌کنه.

کارهایی که **عمداً انجام نمی‌ده**:

- **زیرنویس نمی‌ذاره.** هر دو سبک داستان رو با گرافیک تعریف می‌کنن، نه با زیرنویس. اگه زیرنویس فارسی سوخته روی ویدیو می‌خوای، از [persian-reel](https://github.com/aradazr/persian-reel) ساخته‌ی آراد آذرپناه استفاده کن.
- **کات، اصلاح رنگ و موزیک انجام نمی‌ده.** فرضش اینه که خودت ویدیوت رو (توی CapCut، Premiere یا گوشی) کات زدی، رنگش رو درست کردی و موزیک گذاشتی. صدای ویدیوت دقیقاً همون‌طور که میکس کردی می‌مونه.

## دو سبک ادیت

| | `/reel-story` | `/reel-split` |
| --- | --- | --- |
| **ظاهر** | خودت کل صفحه رو پر می‌کنی. کات به ویدیوهای خودت، استیکر و کارت‌هایی که روی کلمه‌هات ظاهر می‌شن، کاراکتری (ماسکات) که واکنش نشون می‌ده، کلمه‌های غول‌پیکر **پشت سرت**، زوم دوربین، کوچیک شدنت توی یک دایره روی نقشه و… | یک پنل کرم‌رنگ با ویجت‌های انیمیشنی، **۴۵٪ بالای صفحه** رو پر می‌کنه. خودت پایینش ثابت نشستی. |
| **مناسب برای** | داستان، اعلامیه، آپدیت استارتاپ یا زندگی شخصی، دعوت | «این ابزار رو پیدا کردم»، «۵ تا نکته»، آموزش و توضیح |
| **از چی استفاده می‌کنه** | پوشه‌ی B-roll خودت، ماسکات و لوگو (اختیاری) | فقط ویدیوی حرف‌زدنت |
| **انرژی** | بالا — هر ۲ تا ۴ ثانیه یک چیزی عوض می‌شه | آروم و واضح — هر صحنه‌ی پنل یک ایده |
| **پایان** | کلمه‌ی کامنت بزرگ + کارت فالو + لوگو | کلمه‌ی کامنت بزرگ + کارت فالو |

هر دو: بدون زیرنویس، بدون افکت صوتی، صدای خودت دست‌نخورده. و در هر دو:

- **ظاهر ویدیو از مودبورد خودت میاد**، نه از یک قالب تکراری هوش مصنوعی.
- **دکمه‌ها، نوار بالا و کپشن اینستاگرام هیچ‌وقت پوشونده نمی‌شن** — قبل از رندر خودکار چک می‌شه.
- **همه‌ی حرکت‌ها نرم، منحنی و با موشن‌بلر هستن** — هیچ متنی خشک و رباتی جابه‌جا نمی‌شه.

ترفندهای امضای `/reel-story` (همه به‌صورت نمونه‌ی قابل کپی موجودن):

- **متن پشت سرت** — ابزار با هوش مصنوعی خودت رو از ویدیوت جدا می‌کنه (person matte)، پس یک کلمه‌ی غول‌پیکر، لوگوت یا یک دنیای رنگی می‌تونه *بین تو و دیوار* قرار بگیره.
- **حباب فیس‌کم** — توی یک دایره کوچیک می‌شی و یک نقشه یا گرافیک تمام‌صفحه جاش رو می‌گیره، بعد دوباره بزرگ می‌شی.
- **زوم‌اوت موزاییکی** — دوربین اون‌قدر عقب می‌ره که تو یکی از خونه‌های یک دیوار از ویدیوهای خودت می‌شی.
- **کارت دوراهی، تایپ کامنت، پولاروید «همینجا»، B-roll تندشده، مُهر نمره‌ی امتحان، بارون سکه، عقب‌زدن VHS و…** — ۲۵ تکنیک در [`.claude/skills/reel-story/references/techniques.md`](.claude/skills/reel-story/references/techniques.md).

## چطور کار می‌کنه؟

<div dir="ltr">

```
raw/your-video.mp4
   │
   ├─ 1. Transcribe ........ Whisper large-v3 → every word with its exact time
   ├─ 2. Face tracking ..... OpenCV → where your face is (for zooms / framing)
   ├─ 3. B-roll catalogue .. contact sheets of your clips + a notes file Claude keeps
   ├─ 4. Mood board ........ your references → colours, pace, style → a style brief
   │                         that YOU approve before anything is designed
   ├─ 5. Beat plan ......... Claude pins a visual idea to a spoken word every few seconds
   ├─ 6. Assets ............ B-roll trimmed (HDR → SDR, mirrored selfies fixed),
   │                         mascot background removed, AI cut-out of you (matte)
   ├─ 7. Composition ....... Claude writes the animation as HTML + GSAP (HyperFrames)
   │                         with the motion library (curves, motion blur, keyframes)
   ├─ 8. Checks ............ lint, Instagram safe-zone scan, motion lint, snapshots
   │                         with zone guides, then a 12-second REAL test render
   ├─ 9. Render ............ HyperFrames renders 1080×1920 @ 30 fps
   └─ 10. Package + QA ..... your original audio put back, loudness check,
                             contact sheet of the result → final/your-video/
```

</div>

به زبان ساده:

1. **پیاده‌سازی متن** — Whisper تک‌تک کلمه‌هات رو با زمان دقیقشون درمیاره.
2. **ردیابی صورت** — مشخص می‌شه صورتت کجای کادره (برای زوم و کادربندی).
3. **کاتالوگ B-roll** — از ویدیوهای B-rollت عکس‌های خلاصه ساخته می‌شه و Claude یک فایل یادداشت براشون نگه می‌داره.
4. **مودبورد** — از رفرنس‌های خودت رنگ‌ها، سرعت تدوین و سبک درمیاد و Claude یک «بریف سبک» می‌نویسه که **اول خودت تأییدش می‌کنی**.
5. **برنامه‌ی بیت‌ها** — Claude هر چند ثانیه یک ایده‌ی تصویری رو به یک کلمه‌ی گفته‌شده سنجاق می‌کنه.
6. **آماده‌سازی فایل‌ها** — B-rollها بریده می‌شن (HDR به SDR تبدیل می‌شه، سلفی‌های آینه‌ای درست می‌شن)، پس‌زمینه‌ی ماسکات حذف می‌شه، و خودت با هوش مصنوعی از ویدیو جدا می‌شی.
7. **ساخت انیمیشن** — Claude انیمیشن رو با HTML و GSAP (HyperFrames) و کتابخونه‌ی حرکت (مسیر منحنی، موشن‌بلر، کی‌فریم) می‌نویسه.
8. **چک‌ها** — بررسی خودکار، اسکن محدوده‌های امن اینستاگرام، بررسی نرمی حرکت، اسکرین‌شات با راهنمای محدوده‌ها، و بعد یک **رندر واقعی ۱۲ ثانیه‌ای** برای تست.
9. **رندر** — HyperFrames ویدیو رو ۱۰۸۰×۱۹۲۰ با ۳۰ فریم رندر می‌کنه.
10. **بسته‌بندی و کنترل کیفیت** — صدای اصلی خودت دوباره روی ویدیو گذاشته می‌شه، بلندی صدا چک می‌شه، و یک برگه‌ی خلاصه از فریم‌ها ساخته می‌شه.

Claude تدوینگره (می‌خونه، برنامه می‌ریزه، صحنه‌ها رو می‌نویسه و فریم‌ها رو نگاه می‌کنه)؛ کارهای سنگین رو ابزارهای پوشه‌ی `tools/` انجام می‌دن. همه‌چیز **روی کامپیوتر خودت** اجرا می‌شه — بدون آپلود و بدون اشتراک دیگه‌ای جز خود Claude.

## نصب

### ساده‌ترین راه: بذار Claude انجامش بده

<div dir="ltr">

```bash
git clone https://github.com/Jenesyx/arta-edit-studio.git
cd arta-edit-studio
```

</div>

پوشه رو توی Claude Code باز کن و بنویس:

<div dir="ltr">

```
/reel-setup
```

</div>

سیستمت رو چک می‌کنه، قبل از نصب هر چیزی ازت اجازه می‌گیره، فونت‌های رایگان رو دانلود می‌کنه، و با چند سؤال (اسم، آیدی اینستاگرام، زبان، رنگ‌های برند) فایل تنظیمات شخصی `reel.config.json` رو می‌سازه.

### نصب دستی

<div dir="ltr">

```bash
# 1. Python environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 2. PyTorch — copy the right command from https://pytorch.org
#    (NVIDIA GPU → choose a CUDA build). Example for CUDA 12.4:
pip install torch --index-url https://download.pytorch.org/whl/cu124

# 3. The rest
pip install -r requirements.txt
npm install
npx hyperframes doctor        # checks the renderer and its Chrome

# 4. Your settings
cp reel.config.example.json reel.config.json   # then edit it (see below)
```

</div>

بعد فونت‌ها رو توی پوشه‌ی `font/` بذار (بخش [فونت‌ها](#فونتها) رو ببین).

## تنظیمات (`reel.config.json`)

فایل `reel.config.example.json` رو به `reel.config.json` کپی کن. هر کلیدی که ننویسی، مقدارش از فایل نمونه برداشته می‌شه.

| کلید | کارش | مثال |
| --- | --- | --- |
| `creator.name` / `creator.handle` | کارت فالوی آخر ویدیو `@handle` رو نشون می‌ده | `"yourhandle"` |
| `language` | زبانی که توی ویدیو حرف می‌زنی (کد Whisper) | `"fa"`، `"en"`، `"ar"`، `"de"` |
| `whisper_model` | `large-v3` بهترینه؛ `medium` و `small` سریع‌ترن ولی برای فارسی ضعیف‌تر | `"large-v3"` |
| `broll_dir` | پوشه‌ی ویدیوهای B-roll | `"assets/broll"` |
| `brand.name` / `brand.wordmark` | متن معرفی برند (در `/reel-story`) | `"stoodi"` |
| `brand.mascot_dir` | پوشه‌ی عکس‌های کاراکتر | `"assets/mascot"` |
| `brand.mascot_crops` | بریدن حالت‌های کاراکتر از یک برگه‌ی کاراکتر: `{"name": {"file": "sheet.png", "crop": [x, y, w, h]}}` | |
| `brand.logo` | لوگوی مربعی برای پایان ویدیو | `"assets/brand/logo.png"` |
| `palette.*` | رنگ‌های `/reel-story`: `primary`، `secondary`، `ink`، `deep`، `accent`، `accent2`، `highlight`، `paper`، `red`، `green`، `pink`، `social` | کد رنگ hex |
| `split_palette.*` | رنگ‌های پنل `/reel-split`: `cream`، `ink`، `accent`، `accent_deep` (برای متن روی کرم)، `line` | کد رنگ hex |
| `fonts.fa` / `fonts.en` / `fonts.display` | فونت متن فارسی، متن لاتین، و کلمه‌های غول‌پیکر | `"font/Vazirmatn-Medium.ttf"` |
| `split.panel_height` | ارتفاع پنل به پیکسل (۸۶۴ یعنی ۴۵٪، ۹۶۰ یعنی ۵۰٪) | `864` |
| `split.safe` | فاصله‌ی داخلی پنل `[چپ، بالا، راست، پایین]` — بالا رو خالی نگه می‌داره تا نوار بالای اینستاگرام متن رو نپوشونه | `[64, 200, 64, 32]` |
| `moodboard_dir` | پوشه‌ی مودبوردها | `"moodboard"` |
| `instagram_safe_zones` | مستطیل‌هایی `[x0, y0, x1, y1]` که هیچ محتوایی نباید توشون باشه: `header`، `actions`، `footer` | بخش [محدوده‌های امن اینستاگرام](#محدودههای-امن-اینستاگرام) |
| `render.workers` / `render.node_heap_mb` | تعداد پردازش موازی رندر / حافظه‌ی رندرکننده | `3` / `12288` |
| `loudness.lufs` / `loudness.true_peak` | معیار بلندی صدایی که چک نهایی گزارش می‌ده | `-14` / `-1.5` |

### فونت‌ها

فونت‌ها به‌خاطر لایسنس داخل پروژه نیستن. پیش‌فرض‌ها رایگان هستن (لایسنس SIL OFL):

| کلید تنظیمات | فایل پیش‌فرض | دانلود |
| --- | --- | --- |
| `fonts.fa` | `Vazirmatn-Medium.ttf` (وزیرمتن) | [github.com/rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn/releases) |
| `fonts.en` | `Poppins-SemiBold.ttf` | [fonts.google.com/specimen/Poppins](https://fonts.google.com/specimen/Poppins) |
| `fonts.display` | `Poppins-Black.ttf` | همون خانواده |

هر فونت `.ttf` یا `.otf` یا `.woff2` دیگه‌ای هم کار می‌کنه — بذارش توی `font/` و مسیرش رو توی تنظیمات بنویس. (اگه فونت پولی مثل کلمه یا ایران‌سنس داری، می‌تونی از اون استفاده کنی؛ فقط روی گیت‌هاب آپلودش نکن.)

## آماده‌کردن فایل‌ها

1. **ویدیوت ← `raw/`.** هر اسمی، `.mp4` یا `.mov`. ویدیوی عمودی (۹:۱۶) گوشی. اول خودت ادیتش کن (کات، رنگ، موزیک) — Arta Edit Studio فقط لایه‌ی تصویری رو اضافه می‌کنه.
2. **B-roll ← `assets/broll/`** (برای `/reel-story`). ویدیوهای کوتاه گوشی از زندگی و کارت: راه رفتن، درس خوندن، تایپ کردن، صفحه‌ی مانیتور، رویدادها، غذا، میزت. ۱۰ تا ۳۰ کلیپ کافیه. حالت HDR آیفون و سلفی‌های آینه‌ای خودکار درست می‌شن.
3. **ماسکات ← `assets/mascot/`** (اختیاری). عکس‌های PNG یک کاراکتر با حالت‌های مختلف (دست تکون دادن، فکر کردن، ناراحت، جشن…). عکس‌هایی که پس‌زمینه‌ی سفید یا شطرنجی تقلبی دارن (معمول در ابزارهای ساخت تصویر با هوش مصنوعی) خودکار دوربری می‌شن. اسم فایل رو بر اساس حالت بذار: `owl-wave.png`، `owl-think.png` — Claude اسم‌ها رو می‌خونه.
4. **لوگو ← `assets/brand/logo.png`** (اختیاری).

**نکته‌های ضبط:** بالای سرت یک مقدار دیوار خالی بذار (جای «کلمه‌های پشت سرت» همونجاست) · رو به نور بشین · اگه می‌تونی میکروفون یقه‌ای استفاده کن · ویدیوت رو آینه‌ای نکن · صورتت رو تقریباً وسط کادر نگه دار.

## مودبورد (اجباری)

Claude قبل از طراحی هر چیزی، رفرنس‌های **خودت** رو نگاه می‌کنه. همین باعث می‌شه ریلزت شبیه *خودت* باشه و نه یک خروجی تکراری و بی‌روح هوش مصنوعی (AI slop). اگه مودبورد نباشه، Claude کار رو متوقف می‌کنه و ازت می‌خواد یکی بسازی.

<div dir="ltr">

```
moodboard/
├─ default/          ← your general style, used for every video
└─ <video-name>/     ← optional, just for one video (wins over default)
```

</div>

چی توش بذاری (۱۰ دقیقه کافیه):

| چی | چندتا |
| --- | --- |
| اسکرین‌شات از ریلزها یا طراحی‌هایی که دوست داری (ریلز رو نگه دار و اسکرین‌شات بگیر) | ۵ تا ۱۵ |
| ضبط صفحه‌ی کوتاه از حرکت‌ها یا ترنزیشن‌هایی که دوست داری | ۱ تا ۳، هر کدوم حداکثر ۳۰ ثانیه |
| برندت: لوگو، رنگ‌ها، پستی که بهش افتخار می‌کنی | هرچندتا |
| فایل `notes.md`: ۳ تا ۵ کلمه برای حال‌وهوا، چیزهایی که دوست داری، و چیزهایی که **بدت میاد** | ۱ |

نمونه‌ی `notes.md`:

<div dir="ltr">

```markdown
حال‌وهوا: جسور، شاد، تمیز
دوست دارم: کلمه‌های بزرگ زرد، زوم سریع روی صورتم، استیکرهایی که دست‌ساز به نظر میان
بدم میاد: نور نئونی، ایموجی زیاد، متنی که خشک و رباتی حرکت می‌کنه، گرادیان بنفش‌آبی
```

</div>

چی اتفاق میفته: `tools/moodboard.py` از مودبوردت برگه‌ی خلاصه می‌سازه، رنگ‌های اصلی رو درمیاره و **سرعت تدوین** ویدیوهای رفرنست رو اندازه می‌گیره (تعداد کات در دقیقه). بعد Claude یک **بریف سبک** می‌نویسه — حال‌وهوا، رنگ‌ها، تایپوگرافی، حرکت، زبان گرافیکی، شلوغی، بایدها و نبایدها، هر کدوم وصل به یکی از رفرنس‌هات — و نشونت می‌ده. **تا تأییدش نکنی، چیزی ساخته نمی‌شه.** راهنمای کامل: [docs/moodboard.md](docs/moodboard.md).

## محدوده‌های امن اینستاگرام

اینستاگرام رابط کاربری خودش رو روی هر ریلز می‌کشه. هیچ چیزی که باید خونده یا دیده بشه نباید زیرش باشه:

| محدوده | ناحیه (۱۰۸۰×۱۹۲۰) | اینستاگرام اونجا چی می‌ذاره |
| --- | --- | --- |
| `header` | ۲۰۰ پیکسل بالا | نوار وضعیت گوشی، عنوان Reels، دوربین |
| `actions` | ۱۶۰ پیکسل سمت راست، از y=۱۰۰۰ تا ۱۵۲۰ | لایک، کامنت، اشتراک، ارسال، بیشتر |
| `footer` | ۴۰۰ پیکسل پایین | آیدی، دکمه‌ی فالو، کپشن، موزیک |

تصویرهای تمام‌صفحه (خودت، B-roll، پس‌زمینه‌ها) می‌تونن زیر این بخش‌ها برن؛ ولی متن، استیکر، کارت، دکمه، لوگو و ماسکات نه.

- **راهنمای تصویری:** پیش‌نمایش‌ها و رندرهای آزمایشی با یک لایه از این محدوده‌ها، گرید ۱۲۰ پیکسلی، خطوط یک‌سوم و خط وسط ساخته می‌شن (`quick_sheet_guides.jpg` و `qa/sheet_guides.jpg`).
- **چک خودکار:** `tools/safezone.py check <video>` کل تایم‌لاین رو هر ۰.۲ ثانیه در یک مرورگر بی‌صفحه بررسی می‌کنه — **تا وقتی چیزی توی این محدوده‌ها باشه، رندر انجام نمی‌شه.**
- چیدمان گوشی‌ها کمی فرق داره؛ اگه گوشی تو فرق داشت، اندازه‌ها رو توی `reel.config.json` تنظیم کن.

جزئیات: [docs/safe-zones.md](docs/safe-zones.md).

## حرکت نرم

هر ویدیو یک کتابخونه‌ی حرکت (`tools/motion.js`، بر پایه‌ی MotionPath و CustomEase از GSAP) رو بارگذاری می‌کنه:

- **منحنی‌های سرعت اختصاصی:** المان‌ها سریع میان، نرم فرود میان، و با شتاب خارج می‌شن. هیچ چیزی با سرعت ثابت حرکت نمی‌کنه.
- **مسیر منحنی:** `arcIn` و `arcOut` استیکرها و کارت‌ها رو روی یک قوس جابه‌جا می‌کنن، نه روی خط صاف.
- **موشن‌بلر جهت‌دار:** حرکت‌های سریع و ترنزیشن‌ها (whip) در جهت حرکت محو می‌شن. وقتی المان می‌ایسته، کاملاً واضح می‌مونه.
- **پرش و نشستن** (overshoot و settle) برای کلمه‌های بزرگ، **کی‌فریم** برای حرکت‌های چندمرحله‌ای، **زوم نرم دوربین**.
- **بررسی حرکت:** `tools/motion_check.py` قبل از رندر حرکت‌های خطی، پرشی یا یک‌باره رو گزارش می‌کنه.

قوانین و مثال‌ها: [docs/motion.md](docs/motion.md).

## استفاده از دستورها

| دستور | کِی |
| --- | --- |
| `/reel-setup` | یک بار بعد از دانلود پروژه، یا وقتی چیزی کم است |
| `/reel-story <ویدیو> <توضیح>` | ادیت تمام‌صفحه و پرحرکت |
| `/reel-split <ویدیو> <توضیح>` | ادیت با پنل ۴۵٪ |

`<ویدیو>` اسم فایل توی `raw/` است — پسوند، حروف بزرگ و کوچک و خط‌تیره مهم نیست (`StoodiInviteRaw` فایل `stoodi-inviteraw.mp4` رو پیدا می‌کنه).

بعد از فرستادن دستور، Claude:

1. هر چیزی که کم باشه رو یک‌جا می‌پرسه (ادیت شده؟ کلمه‌ی کامنت؟ اسم‌ها؟)،
2. متن رو پیاده می‌کنه، ویدیو، B-rollها و **مودبوردت** رو نگاه می‌کنه،
3. **بریف سبک** رو نشونت می‌ده و منتظر تأییدت می‌مونه،
4. برنامه‌ی بیت‌ها رو می‌نویسه، می‌سازه، محدوده‌های امن و نرمی حرکت رو چک می‌کنه و رندر آزمایشی می‌گیره،
5. ویدیوی کامل رو رندر می‌کنه (حدوداً ۱۰ تا ۱۵ دقیقه برای ۸۰ ثانیه) و فریم‌ها رو چک می‌کنه،
6. بهت می‌گه فایل کجاست و چی توشه.

اگه فقط بگی «ویدیوم رو ادیت کن» و دستوری ننویسی، Claude می‌پرسه کدوم سبک رو می‌خوای.

## خروجی

<div dir="ltr">

```
final/<video>/
├─ <video>.mp4            1080×1920, 30 fps, H.264, your original audio
├─ qa/sheet.jpg           a frame every 3 s — the whole edit at a glance
├─ qa/frame_*.png         10 full-size check frames
├─ transcript.json        word-level transcript
├─ overlay.json / showcase.json   the edit plan (scenes, B-roll used)
└─ config-snapshot.json   the settings it was made with
```

</div>

| فایل | توضیح |
| --- | --- |
| `<video>.mp4` | ویدیوی نهایی ۱۰۸۰×۱۹۲۰، ۳۰ فریم، با صدای اصلی خودت |
| `qa/sheet.jpg` | هر ۳ ثانیه یک فریم — کل ادیت در یک نگاه |
| `qa/frame_*.png` | ۱۰ فریم کامل برای چک |
| `transcript.json` | متن پیاده‌شده با زمان هر کلمه |
| `overlay.json` / `showcase.json` | برنامه‌ی ادیت (صحنه‌ها، B-rollهای استفاده‌شده) |
| `config-snapshot.json` | تنظیماتی که ویدیو باهاش ساخته شد |

چک نهایی ابعاد، فریم‌ریت، بلندی صدا و پیک صدا رو گزارش می‌ده. اگه پیک میکس خودت از ‎-1.5 dBTP بالاتر باشه، چک اینو می‌گه — ولی صدای تو هیچ‌وقت بدون درخواست خودت تغییر نمی‌کنه.

## شخصی‌سازی

- **رنگ، فونت، آیدی، زبان** ← فایل `reel.config.json`.
- **ماسکات خودت** ← عکس‌ها توی `assets/mascot/` با اسم بر اساس حالت.
- **ایده‌های انیمیشنی جدید** ← برای Claude توضیحشون بده. اگه نتیجه رو دوست داشتی بگو «اینو به تکنیک‌های reel-story اضافه کن» تا بخشی از کاتالوگ بشه.
- **نمونه‌ها رو بخون** ← توی پوشه‌ی `examples/` هر صحنه یک تابع کوچیک پایتونه که HTML و GSAP می‌نویسه؛ کپی کن و تغییر بده.
- **نقشه‌ی کشورهای دیگه** ← ابزار نقشه، آلمان رو از یک لیست مختصات (lat, lon) مرزها می‌کشه؛ مرز کشور دیگه رو با همین فرمت اضافه کن.

## رفع مشکلات

| مشکل | دلیل ← راه‌حل |
| --- | --- |
| ویدیوی نهایی تیره یا بی‌رنگه و استیکرها هیچ‌وقت محو نمی‌شن | یک کلیپ HDR (HLG) دست‌نخورده وارد شده ← `finish.py` حالا با پیام «HDR auto-promotion» متوقف می‌شه؛ دستور `story_assets.py <video> broll` رو دوباره اجرا کن (HDR رو تبدیل می‌کنه) |
| رندر وسط کار بی‌صدا متوقف می‌شه | حافظه تموم شده ← `finish.py` خودش با ۱ پردازش دوباره امتحان می‌کنه؛ اگه باز هم متوقف شد، Premiere، بازی‌ها و تب‌های مرورگر رو ببند یا با `PRODUCER_LOW_MEMORY_MODE=1` اجرا کن |
| پیام «no style brief» یا «NO MOOD BOARD» | پوشه‌ی `moodboard/default/` یا `moodboard/<video>/` رو پر کن (بخش [مودبورد](#مودبورد-اجباری)) تا Claude بریف رو بنویسه |
| پیام «content inside Instagram's UI zones» | چک محدوده‌های امن متن یا استیکری زیر رابط اینستاگرام پیدا کرده؛ Claude جابه‌جاش می‌کنه (یا خودت با `--allow-safezone` قبولش می‌کنی) |
| Whisper کرش می‌کنه (exit 139) یا «CUDA out of memory» | یک برنامه‌ی دیگه کارت گرافیک یا رم رو گرفته (بازی، Premiere) ← ببندش و دوباره امتحان کن |
| خطای `font 'fa' not found` | فایل فونت رو توی `font/` بذار و `fonts.*` رو در تنظیمات چک کن |
| کل ویدیو سیاه رندر می‌شه | `dir="rtl"` روی تگ `<html>` گذاشته شده — Claude هیچ‌وقت نباید این کار رو بکنه؛ بهش بگو |
| اسکرین‌شات درست بود ولی رندر خراب | گاهی پیش میاد — دلیل رندر آزمایشی ۱۲ ثانیه‌ای همینه؛ زمانش رو به Claude بگو |
| متن زیر نوار بالا یا دکمه‌های اینستاگرام رفته | دیگه نباید پیش بیاد (چک خودکار)؛ اگه چیدمان گوشی تو فرق داره، `instagram_safe_zones` رو تنظیم کن |
| متن روی B-roll برعکس خونده می‌شه | سلفی آینه‌ای بوده ← Claude اضافه‌ش می‌کنه به `MIRRORED` |
| فیلتر `zscale` پیدا نمی‌شه | نسخه‌ی FFmpeg تو libzimg نداره ← نسخه‌ی «full» رو نصب کن |
